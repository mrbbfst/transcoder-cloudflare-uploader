Довідка та Інструкція користувача

Повний посібник із використання HLS Transcoder R2 для створення та публікації відеопотоків.

1. Швидкий запуск обробки

  1. Перетягніть або оберіть відеофайл у першій вкладці "Транскодер".
  2. Оберіть необхідні якості (наприклад: 1080p, 720p, 480p, 360p).
  3. Оберіть режим обробки: Локальний (CPU) чи Хмарний (GPU).
  4. Натисніть "Розпочати". Після завершення ви отримаєте готове Master Playlist HLS посилання (.m3u8).

2. Режими обробки (CPU vs GPU)

  • Локальне CPU транскодування: Виконується на вашому ПК через системний або вбудований FFmpeg. Безкоштовно. Швидкість залежить від вашого процесора.
  • Хмарне GPU транскодування: Відео завантажується та миттєво кодується на супершвидкому GPU сервері. Потребує входу через Telegram та кредитів на балансі.

3. Покрокова інструкція створення Cloudflare R2 бакета та отримання API ключів

Крок 1: Створення R2 Бакету
  1. Увійдіть у власний акаунт Cloudflare Dashboard.
  2. У боковому меню відкрийте розділ R2 Object Storage.
  3. Натисніть Create bucket.
  4. Вкажіть бажану назву бакета (наприклад: my-hls-videos) та підтвердіть створення.
Крок 2: Отримання API Токена (Credentials)
  1. У розділі R2 Overview праворуч натисніть Manage R2 API Tokens.
  2. Натисніть Create API Token.
  3. Вкажіть права: оберіть Edit (або Read & Write).
  4. Натисніть Create API Token і не закривайте сторінку з ключами.
Крок 3: Внесення ключів у додатку
  1. Скопіюйте Account ID (із панелі R2 Overview).
  2. Скопіюйте Access Key ID та Secret Access Key зі сторінки створеного токена.
  3. Вставте їх у вкладці "Налаштування" додатку та натисніть "Зберегти".
Крок 4: Публічний CDN Домен (Public Domain)
  1. У налаштуваннях вашого бакета (вкладка Settings) знайдіть розділ Public Access.
  2. Підключіть свій домен (Custom Domain, наприклад cdn.yourdomain.com) або увімкніть R2.dev Subdomain.
  3. Вкажіть цей домен у полі Публічний CDN Домен у Налаштуваннях додатку.

4. Оглядач файлів R2 Explorer

Дозволяє переглядати вміст вашого хмарного бакета R2:

  • Копіювати прямі CDN посилання на плейлисти (.m3u8).
  • Видаляти застарілі відеопапки чи окремі сегменти.
  • Завантажувати довільні файли безпосередньо в будь-яку папку.

5. Захист від перебору URL

При увімкненні опції "Додавати криптостійкий суфікс" програма автоматично генерує унікальний рандомний хеш до назви папки. Це гарантує, що ніхто не зможе підібрати посилання на ваші відеопотоки через перебір назв.

6. Сумісність HLS посилань

Сгенеровані master.m3u8 посилання сумісні з усім сучасним медіа-обладнанням: веб-плеєрами (HLS.js, Video.js, Plyr), смарт-ТВ, iOS/Safari та Android додатками з підтримкою адаптивного бітрейту.
